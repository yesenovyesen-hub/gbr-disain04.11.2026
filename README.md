# SIDEQUEST

Мобильный веб-прототип регистрации по email. Дизайн переносится из Figma; текущая форма отправляет и подтверждает код через Amazon Cognito. Аккаунты хранятся в AWS, а не в браузере или локальном JSON-файле. Вход в аккаунт и остальные экраны ещё не реализованы.

## Локальный запуск

В папке `C:\Users\EsenovE\Desktop\disIANFORPROJECT` выполните:

```powershell
npm install
npm start
```

Откройте адрес, который покажет Vite. Для сборки статического сайта выполните `npm run build`; готовые файлы появятся в `dist/`.

## Текущие ограничения

Регистрация подтверждает email, но не создаёт пользовательскую сессию; кнопка входа пока не работает. Телефонный экран сохранён в макете, но регистрация по телефону не включена. Публичная отправка писем зависит от лимита стандартной почты Cognito. Для собственного адреса отправителя позднее потребуется подтверждение адреса в Amazon SES.
